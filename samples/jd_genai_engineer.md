# GenAI Engineer, Nimbus Health (fictional sample)

Nimbus Health is hiring a GenAI Engineer to build LLM-powered assistants for clinicians.

## What you'll do

- Design and ship retrieval-augmented generation (RAG) systems over medical guidelines
- Build agentic workflows with LangGraph that call internal tools and APIs
- Evaluate LLM outputs for accuracy and safety, and run regression evals before every release
- Deploy services with FastAPI and Docker on AWS

## Requirements

- 2+ years of experience in machine learning or software engineering
- Strong Python
- Hands-on experience with LLMs and RAG
- Experience with vector databases (Qdrant, Pinecone or similar)
- LangGraph or LangChain
- FastAPI and Docker

## Nice to have

- Kubernetes
- Fine-tuning open models with LoRA
- Experience with LLM evaluation frameworks such as RAGAS
